#  Technology Stack

## Front-End

### HTML5
Used to build the semantic structure and content of the portfolio,
including sections such as:

- Home
- About
- Experience
- Skills
- Projects
- Community & Volunteering
- Education
- Contact

### CSS3
Used for the complete visual design and responsive layout.

Key CSS features include:

- Responsive design
- CSS Grid and Flexbox
- Glassmorphism
- Gradients
- Animations
- Hover effects
- Responsive typography
- Image galleries
- Mobile layouts
- Custom UI components

### JavaScript (Vanilla JS)

JavaScript is used to provide client-side interactivity without
requiring a JavaScript framework.

Interactive features include:

- Mobile navigation
- Project category filtering
- Scroll-based navigation effects
- Back-to-top functionality
- Scroll reveal animations
- Interactive visual effects
- Reduced-motion support
